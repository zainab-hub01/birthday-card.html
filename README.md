# Animated CSS Birthday Greeting Card

A lightweight web page featuring custom CSS keyframe animations that cycle text colors dynamically across a multi-stage spectrum.

## Features
- **CSS Keyframe Animations:** Dynamic `@keyframes` color-changing effect for animated text transitions.
- **Pure HTML & CSS:** Zero JavaScript dependencies, lightweight and responsive structure.
- **Custom Box Styling:** Structured CSS box styling with background image integration (`birth.png`).

## Prerequisites
- A modern web browser (Google Chrome, Firefox, Microsoft Edge, or Safari).
- Ensure the background image file (`birth.png`) is placed in the same directory as `index.html`.

## How to View
Simply open `index.html` in any web browser.
